# Earlier runs, 2026-11-08 to 2026-11-12

2026-11-08 至 11-12 在旧评测底座上的各批（Claude Code 2.1.319 + deepseek-v4.1-flash；lunamax1 为 gpt-6-luna）。

Back to the [experiment library](../README.md).

These runs used an earlier harness: Claude Code 2.1.319, models reached through a commercial gateway, a lab server instead of the later test machine, and mostly final-attempt accounting (failed attempts were re-run and counted separately). Cost is the fixed-price ledger unless marked [h] (gateway list price). Each comparison is against a native baseline from the same run at the same effort. Per-task data from these runs is not published.

Task sets: `dev-97` (development tasks), `fixed-60` (a fixed 60-task SWE-bench Verified subset used repeatedly), `django-seq-61` (61 Django tasks run in repository order), `held-out-174` (first use), `screen-30`.

Not scored and not listed: a 60-task check on 2026-11-08 voided for a gateway cache fault; `dt2` (v3a/v3b), whose smoke run was aborted by a migration; an extension of cf1 that was planned but never run; effort-level comparisons (max vs. high/medium), which change the model setting rather than add a plugin.
